# Apple Uzbek Clone

Apple rasmiy bosh sahifasining joriy tuzilishidan ilhomlangan, HTML5, CSS3 va Vanilla JavaScript asosidagi o‘zbekcha frontend namoyishi.

## Ishga tushirish

1. `apple-uzbek-clone` papkasini oching.
2. `index.html` faylini brauzerda oching yoki VS Code Live Server orqali ishga tushiring.
3. Internet aloqasi yoqilgan bo‘lishi kerak: mahsulot rasmlari Apple CDN manzillaridan yuklanadi.

## Tuzilma

- `index.html` — sahifa semantik tuzilmasi
- `css/style.css` — asosiy dizayn
- `css/responsive.css` — mobil va planshet moslashuvi
- `css/animations.css` — animatsiyalar va reduced-motion qo‘llovi
- `js/navigation.js` — mobil menyu, qidiruv va savatcha panellari
- `js/carousel.js` — mustaqil karusel boshqaruvi, swipe va klaviatura
- `js/animations.js` — scroll reveal
- `js/main.js` — umumiy sahifa xatti-harakatlari

## Muhim eslatma

Bu mustaqil frontend namoyish loyihasi. Apple Inc. bilan rasmiy aloqasi yo‘q. Apple mahsulot rasmlari Apple’ning ochiq CDN manzillaridan yuklanadi. Ayrim mahsulot nomlari va sahifa mazmuni joriy rasmiy bosh sahifadagi ma’lumotlar asosida berilgan; Apple sayti yangilanganda ular ham o‘zgarishi mumkin.

Qidiruv paneli Apple saytidagi qidiruv sahifasini yangi oynada ochadi. Savatcha hozircha vizual demo holatida, haqiqiy xarid yoki to‘lov tizimiga ulanmagan.
